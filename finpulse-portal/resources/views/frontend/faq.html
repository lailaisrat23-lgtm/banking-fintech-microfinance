The calculator applies a standard amortisation formula to the numbers you enter, using the selected payment frequency. It excludes processing fees, taxes, insurance and any other charges, so results are estimates for learning purposes only, not quotations.

When the annual rate is zero, the calculator divides the loan amount by the number of instalments so the total repayment equals the amount you entered. Interest is shown as BDT 0 rather than a formula result.

Shared page fragments are loaded with fetch, which browsers block for pages opened directly from a file path. Serve the folder over HTTP, for example with PHP or Python, as described in the README.
