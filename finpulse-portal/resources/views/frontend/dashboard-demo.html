Design notes

What this dashboard demonstrates

The layout prioritises the questions a small business owner asks first, then provides detail on demand.

Balance first

The available balance and this month's movement appear before any detail, so the first glance answers the main question.

Filter rather than scroll

Type chips reduce a long list to what matters: incoming, outgoing or pending items awaiting action.

Accessible chart

The bar chart is drawn with CSS and carries a full text alternative describing its trend.

No colour dependence

Statuses combine a symbol, a colour and a written label so meaning survives greyscale or colour-vision differences.
